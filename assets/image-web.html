建立圖片

離開 Qwen Edit、選擇「文字生圖」或「Img2Img」，就會重啟 Image Server 並卸載 mmproj；沒有另一個卸載步驟。任務生成中不可切換。請勿在其他分頁或外部 API 並行送出任務。待辦佇列和已存圖不會刪除。

每張都可個別移除，用 ↑↓ 調整參考圖順序；選錯圖不會送出。待辦任務另會顯示已排入的參考圖預覽。更多參考圖可能增加記憶體需求。

原圖暫存在此瀏覽器，供佇列重開後使用；不會複製到 image-output。改選原圖不會改動已加入的任務。

遮罩需與原圖相同像素尺寸；留空就是普通去噪圖生圖。Qwen Edit 不使用遮罩。

普通去噪圖生圖可不填描述；本版 sd-server 要求非空 prompt，留空時將送出中性文字 the same image（不是 Qwen 修改指令）。來源圖與輸出尺寸不同時，後端可能縮放或裁切。

Qwen Edit：參考圖由視覺編碼器理解後依指令編輯；不使用去噪強度。提示詞請描述要改什麼（例如「只把裙子改成黑色」）。不是像素級保證，背景仍可能變化。

進階設定：Hi-res 高解析度（僅文字生圖）

未勾選「啟用 Hi-res」時，以下選項不會送出、也不影響生圖。使用 sd-server 原生 enable_hr；預設關閉。會增加時間與 VRAM；8GB 建議從小圖開始。沒有 ESRGAN 權重時仍可使用內建放大，不等同純 ESRGAN。放大後上限 200 萬像素、寬高須為 32 的倍數；1.5× 時部分尺寸無法使用。

開啟後單張任務自動使用 Euler、CFG 1、6 步及按輸出尺寸換算的官方 sigma；需要本機 fused LoRA 權重，且不支援 Hi-res 或一般去噪 Img2Img。此模型限非商業研究／評估。關閉不會套用 LoRA。

文字生圖與 Img2Img 走 sdapi 的 lora 陣列送出；Viggle 開啟時兩顆會一起套用（各自 tensor 不重疊），6 步與 sigma 仍依 Viggle 設定。

進階設定：多 LoRA 清單（可同時勾選多個，預設收合）

勾選後才會送出，每個 LoRA 可個別設定強度（0～2）。同一檔案重複選取只套用一次，以 NSFW 欄位或 Viggle 的設定優先。同時套用多顆會增加載入時間與顯存壓力，8 GB 顯卡建議先用較小尺寸測試；LoRA 是否相容仍依該權重說明。

每次加入任務，都會固定當下的描述、尺寸、步數、CFG、種子與取樣器。要換模型請回控制窗停止並重啟 server；佇列中的任務不會因此自動改參數。

    這些模型欄位是什麼？

    生圖模型 / 完整模型

    負責依照文字特徵生成影像。可選獨立 diffusion 權重，或模型自帶完整組件的 checkpoint；兩種形式不要同時填。

    文字編碼器

    將描述轉成模型能理解的特徵，不是幫你寫提示詞。不同模型可能需要 LLM、CLIP-L、CLIP-G 或 T5XXL，請依該模型說明選配。

    VAE

    將模型內部生成的潛空間結果解碼為圖片。部分完整 checkpoint 已內含 VAE，其餘則須另外指定相容檔案。

    本頁提供文字生圖、單張原圖 Img2Img 與最多 10 張參考圖的 Qwen Edit。檔案能選取不等於模型配套相容；若執行失敗，請查看控制窗的 image-output/server.log。圖生圖的去噪改動與指令式圖片編輯是不同流程。
